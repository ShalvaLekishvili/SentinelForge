# Sample data

Only **synthetic or safely sanitized** telemetry belongs in this directory.

- `demo-incident.json` — bundled seven-event portfolio investigation used by the browser demo and tests.
- `.evtx` files are ignored by Git by default because real Windows logs frequently contain usernames, hostnames, paths, and other sensitive data.

Never add production incident evidence, malware samples, credentials, tokens, or customer data to the public repository.
